# Keeper Studio

A little workshop for big stories. An independent fan-made creative studio by **@BugaenkoNastya** for **@Pocket_Dragons_**.

Original characters, eggs, stickers, badges, logos and hatchery artwork from Pocket Dragons Creator Kit 0.8.0. Artwork credits and licence: [legal/CREDITS.txt](legal/CREDITS.txt), [legal/TERMS.txt](legal/TERMS.txt). Creator Kit: https://pocketdragons.io/creator-kit

Music: Keepers Got The Fire, supplied by BugaenkoNastya. Opening video supplied by BugaenkoNastya.

## Hosting

Upload the contents of this folder to the root of a new public GitHub repository. Enable Settings → Pages → Deploy from a branch → main → /(root). No installation or build command is required. Visitors do not need ChatGPT or a GitHub account.

For updates, replace index.html and studio.js, and upload new assets when needed. The visit counter uses the published github.io hostname and project path, so normal updates keep the same counter.

## Privacy and sharing

Drafts, language, volume and music preferences are stored in this browser. Compositions are rendered and exported locally. The studio does not upload your artwork to a server. The published visit counter makes a request to hits.sh; it counts visits, not unique people. X sharing opens the post composer with an editable caption and attribution. Downloaded artwork must be attached by the user before posting.

Audible autoplay depends on the browser. If sound is blocked, use the sound button on the opening or the Music button in the header. Explicit pause and mute preferences are respected.
